# Task 19: Top 10 Products by Sales

## Objective
Identify the top 10 products based on total sales using ranking and sorting.

## Tools Used
- Microsoft Excel
- Python
- Pandas
- Matplotlib

## Dataset
Superstore-style sample sales dataset.

## Steps Performed
1. Loaded the sales dataset.
2. Grouped data by product name.
3. Calculated total sales for each product.
4. Sorted products in descending order.
5. Identified the top 10 products.
6. Created a ranking table and bar chart.
7. Checked for ties in product rankings.

## Deliverables
- Excel workbook containing raw data and Top 10 table.
- Top 10 products bar chart.
- Python-based sales analysis.
- Task report in PDF format.

## Key Learning
- Data grouping and aggregation.
- Sorting and ranking.
- Identifying top-performing products.
- Handling ties in rankings.
- Data visualization.

Successfully completed the Top 10 Products by Sales analysis using Excel and Python as part of the Veda Technology Data Analytics Internship.
